# 预览车辆素材与参考

黄色 SU7、绿色 YU7 和深圳公交为本项目通过内置 imagegen 分别生成的透明背景侧视插画，用于像素城市预览。车身为静态贴图，轮毂旋转、公交门和转向灯由预览程序绘制。它们是风格化表现，并非官方素材或精确车辆模型。

深圳公交外观参考：

- [深圳公交实车照片](https://www.baike.com/wikiid/5232901602796447403)：参考青绿色车身、白色车顶和深色车窗。
- [国家机关事务管理局新能源汽车材料](https://www.ggj.gov.cn/jn/tfiles/ENTYPATH/files/enty/EF20221130026111055468.pdf)：参考其中深圳青绿色新能源公交车照片。
- 车身小屏及站牌所示 3 路和到站时间均为模拟，并不代表深圳真实公交线路或实时信息。

参考项目：

- [Kenney Pixel Vehicle Pack](https://kenney.nl/assets/pixel-vehicle-pack)，CC0；参考侧视车身的清晰轮廓、轮胎层次和有限色块。未直接使用该项目素材。
- [2D Horizontal Car](https://opengameart.org/content/2d-horizontal-car)，Segel，CC0；参考行驶时的轮胎表现。未直接使用其素材或动画。
