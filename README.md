# 深圳像素城市：桌面壁纸原型

本项目使用已确认的 `exec-27c3a240` 效果图，当前是可运行的桌面壁纸原型。

## 运行

- 双击 `Preview.cmd` 打开窗口预览：`F1` 显示或隐藏信息，`F11` 切换全屏，`Esc` 退出。信息面板中的下拉菜单可以选择屏幕适配方式。
- 双击 `Wallpaper.cmd` 启动实验性桌面壁纸。壁纸默认显示在主显示器，右下角系统托盘的图标菜单中选择 **Exit wallpaper** 退出。若系统托盘没有立即显示图标，请查看隐藏图标区域。
- 默认使用“城市放大”，按原比例放大城市，两侧各裁切约 8%，并用天空填满剩余空间；适合 2880×1800 的主屏。在壁纸托盘菜单的 **Display mode** 中也可切换 **Fill (crop)**、**Fit (letterbox)**、**Stretch** 或 **Enlarged scene (slight crop)**，设置在预览和壁纸间共享。
- 桌面壁纸使用 Windows 桌面窗口层级，已在当前 Windows 环境完成附着及自动清理测试；与 Wallpaper Engine 同时运行时可能相互覆盖。如果桌面未正确显示，退出本程序并使用预览模式。
- 如果文件被移动到另一台电脑，须在项目的 `.tools/godot/` 下放置 Godot 4.6 Windows 程序 `Godot_v4.6-stable_win64.exe`；这个目录不会随 Git 提交。也可以在安装后用 Godot 打开 `project.godot`。

## 当前实现

- 根据用户选定的 2172×724 画面制作分层背景；支持填充、完整显示和拉伸，窗口和屏幕尺寸变化时自动重新适配。
- 公交和汽车沿双向车道行驶，轿车接近公交时从更远的车道绕行，公交轮毂随行驶转动、停站时停止；公交模拟减速、停靠和驶离，地铁模拟缓慢进站、停留和加速离站。中央公交站使用半透明分层绘制。车辆位置和班次为画面模拟，不对应实时交通。
- 18 位居民使用四帧行走动作，在海边、地面与站台活动（12 种造型）；同作品角色相遇会短暂问候，人物间歇显示表情气泡。下雨时部分人撑伞，没有伞的地面行人前往公交站避雨。
- 部分行人在模拟公交或地铁停靠时向车辆移动、渐隐上车，随后返回场景；这只是演示行为，不代表真实乘客轨迹。站台屏幕显示 3 号线华新站、本机时间和与画面同步的模拟列车状态。
- 公交及轿车使用新素材并按车轮位置决定遮挡顺序；天空偶尔出现动画飞船彩蛋。
- 街灯叠加光晕在本机 18:00 起五分钟内渐亮，6:00 起五分钟内渐暗；原背景的灯光仍是静态的。
- 太阳在本机 6:00–18:00 之间沿简化轨迹移动并渐隐；昼夜色彩平滑过渡。此轨迹是画面模拟，不是精确的深圳日出日落时间。
- 获取深圳天气，显示温度、天气类别、数据时间和来源；每 30 分钟更新，失败后 5 分钟重试，缓存可供离线查看。多云或雨天显示缓慢移动的云层，雨类天气时显示雨线。
- 部分环境配置了 `HTTPS_PROXY` 时，支持无认证的 `http://host:port` 代理。当前天气来自 [Open-Meteo](https://open-meteo.com/en/docs)，是基于天气模型的数据，并非逐分钟实测。其免费服务的商业用途和署名条件需要在正式发布前核对。

## 尚未实现

扶梯尚未拆分成独立动画；也没有真实线路和班次、居民档案、悬停查询、季节切换、突发事件、多显示器配置或全屏降耗。不要把图中的车辆当作真实位置。后续需要核验深圳交通数据并继续拆分素材，逐步接入这些功能。

桌面壁纸模式目前隐藏状态面板；请在预览模式查看时间和天气，并可在托盘菜单切换画面适配或退出。

## 素材来源与参考项目

- [Pixel Commute](https://github.com/nikunjsingh93/pixel-commute)：参考交通运动的组织思路；没有直接使用其代码或素材。
- [Pixelorama](https://github.com/Orama-Interactive/Pixelorama)：参考像素动画和精灵表工作流；没有直接使用其代码或素材。
- [Animated spaceships](https://opengameart.org/content/animated-spaceships)：使用 Jull 创作的 UFO 动画精灵，原作者标注为 CC0。

角色、车辆及去人背景素材为本项目生成。人物移动按实际位移推进步态，画面目标帧率为 60 FPS；当前行走素材仍仅有四帧。公交车轮使用随位移转动的轮毂效果；车身和轿车仍使用单张精灵。人物、乘车、问候和天气反应均为轻量模拟，暂不包含真实客流、完整上下车路径或复杂关系系统。
