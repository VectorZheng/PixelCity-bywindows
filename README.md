# 深圳像素城市：桌面壁纸原型

本项目使用已确认的 `exec-27c3a240` 效果图，当前是可运行的桌面壁纸原型。

## 运行

- 双击 `Preview.cmd` 打开独立窗口预览（包含最新实验调整）：`F1` 显示或隐藏信息，`F11` 切换全屏，`Esc` 退出。信息面板中的下拉菜单可以选择屏幕适配方式，并可切换晴、雨、雪、雾或雷雨演示；演示不改变真实天气数据。
- 双击 `Wallpaper.cmd` 启动固定版本的实验性桌面壁纸；预览的代码、素材及显示设置改动不会自动影响壁纸。壁纸默认显示在主显示器，右下角系统托盘的图标菜单中选择 **Exit wallpaper** 退出。若系统托盘没有立即显示图标，请查看隐藏图标区域。
- 预览默认使用“城市放大”，按原比例放大城市，在 2880×1800 屏幕两侧各裁切约 20%，减少天空并放大人物。预览将两侧地铁入口及扶梯向内收拢，保留完整结构；壁纸保留其原有取景。在壁纸托盘菜单的 **Display mode** 中也可切换 **Fill (crop)**、**Fit (letterbox)**、**Stretch** 或 **Enlarged scene (slight crop)**，预览与壁纸的显示设置分别保存。
- 桌面壁纸使用 Windows 桌面窗口层级，已在当前 Windows 环境完成附着及自动清理测试；与 Wallpaper Engine 同时运行时可能相互覆盖。如果桌面未正确显示，退出本程序并使用预览模式。
- 如果文件被移动到另一台电脑，须在项目的 `.tools/godot/` 下放置 Godot 4.6 Windows 程序 `Godot_v4.6-stable_win64.exe`；这个目录不会随 Git 提交。也可以在安装后用 Godot 打开 `project.godot`。

## 预览当前实现

- 根据用户选定的 2172×724 画面制作分层背景；支持填充、完整显示和拉伸，窗口和屏幕尺寸变化时自动重新适配。
- 两侧公交站都有候车区和模拟到站显示，车辆分别在对应站台停靠；预览公交车参考深圳新能源公交的青绿白涂装，使用生成的侧视素材；海边站的候车人物面向车道，近侧站的候车人物背对画面。公交和汽车沿双向车道行驶，轿车接近公交时从更远的车道绕行并打灯，预览中的黄色 SU7 风格轿车和绿色 YU7 风格 SUV 使用独立的侧视素材；部分轿车模拟减速、停车接人和驶离，车辆轮毂随行驶转动、停站时停止；公交模拟减速、停靠和驶离，地铁使用蓝绿配色的六节风格化列车，模拟缓慢进站、停留和加速离站。中央公交站使用半透明分层绘制。车辆位置和班次为画面模拟，不对应实时交通。
- 预览中 18 位居民使用各不相同的角色形象和四帧行走动作，在海边、地面与站台活动；移动速度经过放缓，步态过渡更柔和。同作品角色相遇会短暂问候，人物间歇显示表情气泡；下雨时部分人撑伞，没有伞的地面行人前往公交站避雨。
- 居民按本机时段、个人和行程次数选择住宅、办公区、商店或公园等画面目的地，步行后短暂停留；部分较长行程会选择本侧公交或地铁。公交乘客会走向站台、坐下等待、起身并在车门开启时上车；部分避雨乘客会坐在站台。候车者面朝车道，雨天还有预设人物收伞、查看公交站牌；一位乘客会在轿车停靠时上车，并在下一次停靠时下车。乘客上车后会保持在车辆内，直到下一次停站开门才下车；收伞、看站牌和轿车接人仍是少数预设人物的演示。
- 部分行人在模拟公交或地铁停靠时向车辆移动、渐隐上车，再在车辆下一次停站时下车；场景只有单个可见站点，行程并非真实线路或完整城市交通。华新站站台采用浅色墙面、蓝色站名牌和玻璃屏蔽门，屏蔽门与列车停站开门同步；站台屏幕显示 3 号线华新站、本机时间和与画面同步的模拟列车状态；公交站显示模拟 3 路及与画面车辆同步的秒数，不是真实公交信息。
- 公交及轿车使用新素材并按车轮位置决定遮挡顺序；天空偶尔出现动画飞船彩蛋。
- 街灯叠加光晕在本机 18:00 起五分钟内渐亮，6:00 起五分钟内渐暗；原背景的灯光仍是静态的。
- 树叶有轻微晃动，建筑窗灯随时间闪烁；太阳在本机 6:00–18:00 之间沿简化轨迹移动并渐隐；昼夜色彩平滑过渡。此轨迹是画面模拟，不是精确的深圳日出日落时间。
- 获取深圳天气，显示温度、天气类别、数据时间和来源；每 30 分钟更新，失败后 5 分钟重试，缓存可供离线查看。多云时显示移动云层；雨、雪、雾使用 Weather FX Free 动画，雨点覆盖车道和人行道，在地面形成水花，并避开公交站棚和地铁站入口；雷雨另外显示短暂的闪电。
- 部分环境配置了 `HTTPS_PROXY` 时，支持无认证的 `http://host:port` 代理。当前天气来自 [Open-Meteo](https://open-meteo.com/en/docs)，是基于天气模型的数据，并非逐分钟实测。其免费服务的商业用途和署名条件需要在正式发布前核对。

## 尚未实现

扶梯尚未拆分成独立动画；也没有真实线路和班次、居民档案、悬停查询、季节切换、突发事件、多显示器配置或全屏降耗。不要把图中的车辆当作真实位置。后续需要核验深圳交通数据并继续拆分素材，逐步接入这些功能。

桌面壁纸模式目前隐藏状态面板；请在预览模式查看时间和天气，并可在托盘菜单切换画面适配或退出。

## 素材来源与参考项目

- [Weather FX Free](https://github.com/Spyridon-Pikoulas/godot-weather-fx-free)：实际使用其雨、雪、雾着色器，并修改雨的站棚遮挡。Weather FX Free by heyheythere - https://heyheythere.itch.io/weather-fx-free - CC BY 4.0；许可全文见 `addons/weather_fx/LICENSE.txt`。免费版仅包含这三种效果，未包含付费完整版的其他效果。
- [2D Train Demo](https://github.com/moonbench/simple-godot-train)：参考车辆运行、加减速的实现思路；未复制其代码或素材。
- [Kenney Pixel Vehicle Pack](https://kenney.nl/assets/pixel-vehicle-pack)：参考其侧视车辆的像素轮廓、配色和轮胎层次；未直接使用素材，许可 CC0。
- [2D Horizontal Car](https://opengameart.org/content/2d-horizontal-car)：参考 Segel 的十帧侧视车辆动画；因风格不同未直接使用其素材。
- [Cities: Skylines 官方介绍](https://www.paradoxinteractive.com/games/cities-skylines/about)：参考按昼夜变化的居民日程和交通系统概念；本项目使用独立实现，并非该游戏代码。
- [Pixel Commute](https://github.com/nikunjsingh93/pixel-commute)：参考交通运动的组织思路；没有直接使用其代码或素材。
- [Pixelorama](https://github.com/Orama-Interactive/Pixelorama)：参考像素动画和精灵表工作流；没有直接使用其代码或素材。
- [Animated spaceships](https://opengameart.org/content/animated-spaceships)：使用 Jull 创作的 UFO 动画精灵，原作者标注为 CC0。

角色、车辆及去人背景素材为本项目生成。人物移动按实际位移推进步态，画面目标帧率为 60 FPS；当前行走素材仍仅有四帧。公交与地铁的轮毂随位移转动，停站时显示车门开合；车身和轿车仍使用单张精灵。人物、乘车、问候和天气反应均为轻量模拟，暂不包含真实客流、完整上下车路径或复杂关系系统。

黄色 SU7、绿色 YU7 与深圳公交为生成的风格化素材，生成提示词和参考项目见 [车辆素材说明](docs/vehicle-art.md)。

深圳地铁列车和站台为风格化重建，参考图片、来源和生成提示词见 [地铁素材说明](docs/metro-art.md)。
