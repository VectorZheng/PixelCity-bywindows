# 深圳像素城市：桌面壁纸原型

本项目使用已确认的 `exec-27c3a240` 效果图，当前是可运行的桌面壁纸原型。

## 运行

- 双击 `Preview.cmd` 打开独立窗口预览（包含最新实验调整）：`F1` 显示或隐藏信息（淡入淡出），`F11` 切换全屏，`Esc` 退出。信息面板中的下拉菜单可以选择屏幕适配方式、像素网格（关闭 / 细 / 粗），并可切换晴、雨、雪、雾或雷雨演示；演示不改变真实天气数据。
- 预览中把鼠标停在任意居民身上，会显示其身份卡：姓名、年龄、生日、工作、家、心情、接下来要做什么和生活习惯。身份为虚构生成，并与该居民的实际行为对应（例如总在公交站等车的人是坐 3 路通勤的，下雨就去站棚躲雨的人“常忘带伞”，会互相打招呼的两人是老同学）；“接下来”随模拟状态实时变化。
- 双击 `Wallpaper.cmd` 启动固定版本的实验性桌面壁纸；预览的代码、素材及显示设置改动不会自动影响壁纸。壁纸默认显示在主显示器，右下角系统托盘的图标菜单中选择 **Exit wallpaper** 退出。若系统托盘没有立即显示图标，请查看隐藏图标区域。
- 预览默认使用“城市放大”，按原比例放大城市，在 2880×1800 屏幕两侧各裁切约 20%，减少天空并放大人物。华新站在本侧只保留左侧入口（一上一下两部扶梯），原右侧入口改为马路对面海边人行道上的“华新 B 口”；画面变窄时入口向内收拢；壁纸保留其原有取景。在壁纸托盘菜单的 **Display mode** 中也可切换 **Fill (crop)**、**Fit (letterbox)**、**Stretch** 或 **Enlarged scene (slight crop)**，预览与壁纸的显示设置分别保存。
- 桌面壁纸使用 Windows 桌面窗口层级，已在当前 Windows 环境完成附着及自动清理测试；与 Wallpaper Engine 同时运行时可能相互覆盖。如果桌面未正确显示，退出本程序并使用预览模式。
- 如果文件被移动到另一台电脑，须在项目的 `.tools/godot/` 下放置 Godot 4.6 Windows 程序 `Godot_v4.6-stable_win64.exe`；这个目录不会随 Git 提交。也可以在安装后用 Godot 打开 `project.godot`。

## 预览当前实现

- 根据用户选定的 2172×724 画面制作分层背景；支持填充、完整显示和拉伸，窗口和屏幕尺寸变化时自动重新适配。
- 两侧公交站都有候车区和模拟到站显示，车辆分别在对应站台停靠；预览公交车参考深圳新能源公交的青绿白涂装，使用生成的侧视素材；海边站的候车人物面向车道，近侧站的候车人物背对画面。公交和汽车沿双向车道行驶，轿车接近公交时从更远的车道绕行并打灯，预览中的黄色 SU7 风格轿车和绿色 YU7 风格 SUV 使用独立的侧视素材；部分轿车模拟减速、停车接人和驶离，车辆按屏幕像素对齐绘制，轮毂为静态（旋转辐条在缩小后会频闪），移动时不再闪烁；公交模拟减速、停靠和驶离，地铁使用蓝绿配色的六节风格化列车，模拟缓慢进站、停留和加速离站。中央公交站使用半透明分层绘制。车辆位置和班次为画面模拟，不对应实时交通。
- 预览中 18 位居民使用各不相同的角色形象和四帧行走动作，在海边、地面与站台活动；移动速度经过放缓，步态过渡更柔和。同作品角色相遇会短暂问候，人物间歇显示表情气泡；下雨时部分人撑伞，没有伞的地面行人前往公交站避雨。
- 居民按本机时段、个人和行程次数选择住宅、办公区、商店或公园等画面目的地，步行后短暂停留；部分较长行程会选择本侧公交或地铁。公交乘客会走向站台、坐下等待、起身并在车门开启时上车；部分避雨乘客会坐在站台。候车者面朝车道，雨天还有预设人物收伞、查看公交站牌；一位乘客会在轿车停靠时上车，并在下一次停靠时下车。乘客上车后会保持在车辆内，直到下一次停站开门才下车；收伞、看站牌和轿车接人仍是少数预设人物的演示。
- 部分行人在模拟公交或地铁停靠时向车辆移动、渐隐上车，再在车辆下一次停站时下车；场景只有单个可见站点，行程并非真实线路或完整城市交通。华新站站台采用浅色墙面、蓝色站名牌和玻璃屏蔽门，屏蔽门与列车停站开门同步；站台屏幕显示 3 号线华新站、本机时间和与画面同步的模拟列车状态；公交站显示模拟 3 路及与画面车辆同步的秒数，不是真实公交信息。
- 公交及轿车使用新素材并按车轮位置决定遮挡顺序。天空中不时有客机缓慢飞过（往返宝安机场），高空客机在身后留下会随风漂移、变宽并消散的凝结尾迹；偶尔有直升机低空经过。鼠标悬停可查看航班/任务、航线、高度和速度（均为模拟）。
- 街灯叠加光晕在本机 18:00 起五分钟内渐亮，6:00 起五分钟内渐暗。夜晚另有一层叠加光照：路灯在海边步道投下光池，公交和轿车亮起前灯光束、尾灯与车窗，站棚、到站屏和地铁口标识发光；雨天车辆白天也开灯，湿路面映出灯光倒影。

## 画面处理

- 人物有两组形象，可在左上角信息面板的“人物”选项切换并自动保存：动漫角色（原素材），或写实市民。写实市民由 `tools/gen_real_people.py` 按程序逐肢体绘制为像素画（约 7.5 头身、8 帧行走），衣着按各自身份设计，例如站务员制服、健身教练运动装、大学生双肩包；不是照片，也不对应真实人物。两组共用同一套身份与行为。
- 候车时人物会不时看手机（夜间屏幕微亮），车辆即将进站时收起手机看向来车方向；上车分为走到车门、迈上车厢、进入车内渐隐三个阶段，下车反向进行。
- 公交站参照深圳智慧电子站牌：蓝色站名栏和时间、黄色线路牌，以及“距本站 2 站 / 1 站 / 即将进站 / 已到站”四种状态；附独立站牌，路面画有黄色公交港湾标线与“公交车站”字样。到站信息仍为模拟。
- 地铁屏蔽门上方为蓝底白字的盖板，轮流显示“华新 Huaxin”“3号线 Line 3”“往 坪地六联”，每扇门有线路圆标和门号，开门时门号牌转为绿色。列车每节车厢有琥珀色“3号线 坪地六联”LED 牌；车门打开后显示明亮的车厢内部与扶杆。3 号线使用天蓝色标识。
- 扶梯穿过楼板的开口改为由楼板边缘向下渐淡的阴影，并加楼板边沿，不再出现黑色色块。
- 背景不再抠图：`tools/gen_city.py` 以 1 个纹素 = 1 个场景像素程序化绘制整条像素风街景——平安金融中心、华润“春笋”、京基 100、地王大厦、赛格广场、腾讯滨海大厦与市民中心屋顶等地标剪影，前后几层写字楼、高层住宅和老式步梯楼交错，下方是深圳湾、海堤、榕树与大王椰绿带、人行道和收窄后的马路。脚本同时输出遮罩（天空、海面、远近雾化深度、树冠）和窗户表（每扇窗一个编号、写字楼/住宅/航空障碍灯/灯光秀立面）。修改后运行 `python tools/gen_city.py`。
- 大幅缩小绘制的生成素材（车辆、人物、地铁、扶梯、站棚、云、花坛）使用 mipmap 与三线性过滤，移动时不再闪烁；光晕和天空使用平滑渐变；站牌文字使用距离场字体，放大后保持清晰。
- 候车与坐下的人物直接使用各自角色的素材：上半身随坐下降低，腿部按角色裤子与鞋子的颜色折向前方；候车者面朝车辆驶来的方向。
- 人物停下时直立并脚：写实市民和路人有单独生成的站姿（`real-stand-*.png` / `crowd-stand-*.png`），动漫角色取双脚最近的一帧并收拢双腿。地铁站一侧公交站（近侧站棚）的座位上，坐下的人面朝车道，因此画面里看到的是背影。
- 早晚高峰有大量路人经左侧入口的上下行扶梯进出站，并在站台上走动；去对面 B 口的人在入口处渐隐。站台下方三根装饰柱统一为同一宽度，均位于两扇屏蔽门之间。
- 车辆信息中的地点为真实地名，车牌最后一位一律显示为 `x`（如 `粤B·D1234x`），不显示完整车牌。
- 像素网格是可选的全屏后处理：画面按场景像素（细）或两倍场景像素（粗）统一成大小一致的像素块，文字、细线、天气与背景共用同一网格；每格不足约 1.8 个屏幕像素时自动关闭。在 2880×1800 下实测仍高于 60 FPS 目标。
- 天气切换约 2.5 秒淡入淡出，闪电为两次闪烁。
- 天空、太阳、月相、星星和云按真实时间与天气实时生成，并用有序抖动画成像素色阶，不再有紫色调；远处楼宇随当前天色雾化；树冠按整像素随风摆动。每扇窗户各自在 40–280 秒后随机开或关，写字楼与住宅按不同作息（写字楼白天满、夜里加班渐少，住宅傍晚最亮、凌晨几乎全灭）；高楼顶有闪烁的红色航空障碍灯，19:30–22:00 地标立面有灯光秀。
- 获取深圳天气，显示温度、天气类别、数据时间和来源；每 30 分钟更新，失败后 5 分钟重试，缓存可供离线查看。多云时显示移动的像素云；雨、雪、雾由 `shaders/weather_pixel.gdshader` 在场景像素网格上绘制：雨是整像素移动的短雨丝并在路面溅起 3 像素水花，雪是 1–2 像素雪片，雾是抖动分层的像素雾；不落入两座公交站棚和地下车站；雷雨另外显示短暂的闪电。
- 部分环境配置了 `HTTPS_PROXY` 时，支持无认证的 `http://host:port` 代理。当前天气来自 [Open-Meteo](https://open-meteo.com/en/docs)，是基于天气模型的数据，并非逐分钟实测。其免费服务的商业用途和署名条件需要在正式发布前核对。

## 尚未实现

动漫角色的行走素材仍仅有四帧（帧间仅保留一两帧的过渡），坐姿与候车姿势由现有素材拼合，未单独绘制；也没有真实线路和班次、季节切换、突发事件、多显示器配置或全屏降耗。居民身份为虚构生成，不对应真实人物。不要把图中的车辆当作真实位置。后续需要核验深圳交通数据并继续拆分素材，逐步接入这些功能。

桌面壁纸模式目前隐藏状态面板；请在预览模式查看时间和天气，并可在托盘菜单切换画面适配或退出。

## 素材来源与参考项目

- [Weather FX Free](https://github.com/Spyridon-Pikoulas/godot-weather-fx-free)：壁纸版仍使用其雨、雪、雾着色器；预览已改用自写的像素天气着色器。Weather FX Free by heyheythere - https://heyheythere.itch.io/weather-fx-free - CC BY 4.0；许可全文见 `addons/weather_fx/LICENSE.txt`。免费版仅包含这三种效果，未包含付费完整版的其他效果。
- [2D Train Demo](https://github.com/moonbench/simple-godot-train)：参考车辆运行、加减速的实现思路；未复制其代码或素材。
- [Kenney Pixel Vehicle Pack](https://kenney.nl/assets/pixel-vehicle-pack)：参考其侧视车辆的像素轮廓、配色和轮胎层次；未直接使用素材，许可 CC0。
- [2D Horizontal Car](https://opengameart.org/content/2d-horizontal-car)：参考 Segel 的十帧侧视车辆动画；因风格不同未直接使用其素材。
- [Cities: Skylines 官方介绍](https://www.paradoxinteractive.com/games/cities-skylines/about)：参考按昼夜变化的居民日程和交通系统概念；本项目使用独立实现，并非该游戏代码。
- [Pixel Commute](https://github.com/nikunjsingh93/pixel-commute)：参考交通运动的组织思路；没有直接使用其代码或素材。
- [Pixelorama](https://github.com/Orama-Interactive/Pixelorama)：参考像素动画和精灵表工作流；没有直接使用其代码或素材。
- [Animated spaceships](https://opengameart.org/content/animated-spaceships)：Jull 创作的 UFO 精灵（CC0），仅壁纸版仍在使用；预览改为程序绘制的飞机。

角色、车辆及去人背景素材为本项目生成。人物移动按实际位移推进步态，画面目标帧率为 60 FPS；当前行走素材仍仅有四帧。公交与地铁停站时显示车门开合；车身和轿车仍使用单张精灵。人物、乘车、问候和天气反应均为轻量模拟，暂不包含真实客流、完整上下车路径或复杂关系系统。

黄色 SU7、绿色 YU7 与深圳公交为生成的风格化素材，生成提示词和参考项目见 [车辆素材说明](docs/vehicle-art.md)。

深圳地铁列车和站台为风格化重建，参考图片、来源和生成提示词见 [地铁素材说明](docs/metro-art.md)。
